# 《족보 없는 집》 이벤트 카드 작성 규칙

## 게임 소개
1950년 피란민 부부가 서울 변두리 판자촌 '버드내'에 정착해, 한 동네에서 3세대가 모두 세상을 떠날 때까지(대개 2080~2100년대, 늦으면 2110년) 집안을 꾸려 가는 가문 경영 시뮬레이션이다. **한국 현대사를 한 집안의 눈으로 관통하는 작품**이다. 큰 역사 사건(전쟁, 4·19, 산업화, 민주화, 외환위기, 월드컵, 세월호, 코로나 등)은 별도의 '시대 이벤트'로 이미 만들어져 있으니, 카드에서는 그 시대를 살아가는 **한 집안의 일상과 대소사**를 그린다. 시대 분위기는 배경으로 녹이되, 정치적 평가나 특정 진영의 시각은 넣지 않는다.

매년 여름 '올해 생긴 일' 카드가 4~9장 나오고, 플레이어는 카드마다 선택지 하나를 고른다. 결과는 바로 반영된다.

## 파일 형식
JavaScript 파일 하나에 배열 하나만 정의한다. 변수 이름은 지시받은 이름을 쓴다.

```js
const CARDS_A=[
 {id:'a-001',slot:'집안',y:[1955,1965],who:'kid',title:'첫 운동화',text:'{subj}{subj:이/가} 고무신 대신 운동화를 사 달라고 조른다. 반에서 운동화 없는 아이는 몇 안 된다.',
  ch:[{t:'사 준다 (2)',need:{money:2},fx:{money:-2,aff:2}},
      {t:'고무신을 기워 신긴다',fx:{grudge:1,gap:{f:-1}}},
      {t:'명절에 사 주기로 약속한다',fx:{aff:1,chain:{id:'a-001b',in:1}}}]},
 {id:'a-001b',slot:'자녀',chainOnly:true,who:'kid',title:'약속한 운동화',text:'설에 약속한 운동화를 사 줄 때가 됐다.',
  ch:[{t:'약속을 지킨다 (2)',need:{money:2},fx:{money:-2,aff:2}},{t:'형편이 안 된다며 미룬다',fx:{grudge:2}}]},
];
```

## 카드 필드
- `id`: 지시받은 접두어로 시작하는 고유 문자열.
- `slot`: 아래 6개 중 하나.
  - `가족`: 어른(대표·배우자·며느리·사위·노인)의 일.
  - `자녀`: 아이·청소년·결혼 안 한 자녀의 일.
  - `동네`: 이웃 집안과 주고받는 일. 반드시 `nb`가 있어야 한다.
  - `시대`: 그 시대 생활 변화(물건, 유행, 일자리, 제도)를 집안이 겪는 일.
  - `집안`: 집안 대소사(제사, 돌잔치, 환갑, 이사, 집 수리, 병, 사고, 명절, 친척, 살림, 돈 문제).
  - `공통`: 어느 슬롯에 넣어도 되는 일.
- `y:[시작년, 끝년]`: 등장 가능 연도(1950~2110). 2021년 이후는 가상의 미래. chainOnly 카드는 생략.
- `who` (선택): 카드 주인공. 정하면 조건에 맞는 사람이 무작위로 뽑히고 `{subj}`로 이름을 쓸 수 있다.
  - `rep` 집안 대표 / `spouse` 대표의 배우자 / `adult` 집에 사는 18세 이상(대표 제외) / `elder` 60세 이상 / `inlaw` 며느리·사위
  - `kid` 7~13세 / `teen` 14~19세 혈육 / `young` 0~6세 / `single` 21세 이상 미혼 혈육 / `student` 학교에 다니는 7~23세
  - `adultStudy` 직장이나 공부를 하는 18세 이상 / `adultKid` 다음 세대 18세 이상 혈육 / `grandkid` 손주 세대 / `worker` 장사나 기술 일을 하는 18세 이상 / `any` 집에 사는 누구나
- `wc` (선택): 주인공 조건 함수 `p=>...`. 쓸 수 있는 값: `p.sex`('m'|'f'), `age(p)`, `p.desire`('출세'|'부'|'안정'|'자유'|'사랑'|'인정'), `p.edu`(0 없음,1 국졸,2 고졸,3 대졸), `p.f.married`, `p.f.official`, `p.slot`('trade'|'craft'|'study'|'help'|'home'|'rest'|'care'), `p.tal.셈` 등 능력치(0~10), `p.pers.모험` 등 성격(0~10), `p.grudge`(0~10), `p.aff`(-10~10).
- `nb` (동네 카드 필수): `any` 아무 이웃 / `maxj` 정이 가장 높은 이웃 / `minj` 정이 가장 낮은 이웃 / 특정 집: `tobagi`(토박이 소작농→땅 부자→재개발 조합장), `pirani`(같은 배 피란민 상인→도매상→IMF 부도), `gwabu`(과부와 자식 셋→아들 은행원→복지관장), `yangban`(몰락 양반 교사→교수 집안→해외), `smith`(대장간→공장 사장→로봇 정비), `jumak`(술집·복덕방→부동산 중개→동네 소식 채널). 이웃은 1990년대부터 이사를 가기도 하니 특정 집보다 `any`, `maxj`, `minj`를 주로 쓴다.
- `ncond` (선택): 이웃 조건 `n=>n.j>=3` (n.j는 정 -10~10).
- `cond` (선택): 카드 등장 조건 함수 `()=>...`. 쓸 수 있는 값: `S.year`, `S.money`(내부 단위), `S.face`(체면 0~100), `S.house`('shack' 판잣집|'own' 내 집|'apt' 아파트), `S.tradeY`/`S.craftY`(장사·기술 경력 연수), `S.tradeSt`/`S.craftSt`(1~3 단계: 장사 좌판→점포→도매, 기술 공장 일→기능공→우리 공장), `S.land`(땅 필지 수), `S.repu`(가게 평판 0~100), `S.flags.xxx`, `S.curGen`(지금 세대 1~3), `S.biz`(장사 업종: 'stall' 좌판,'rice' 쌀가게,'food' 식당,'cloth' 옷가게,'hard' 철물점,'store' 구멍가게·편의점,'radio' 전파사,'bakery' 제과점·카페,'video' 비디오·PC방,'chicken' 치킨집,'online' 온라인 쇼핑몰), `S.lands`(땅 필지 배열, 각 `{kind:'farm'|'lot'|'hill'|'road', nm, py, lease, bld}`).
- `major:true` (선택): 인생이 바뀌는 큰일. 화면에 '중요' 도장이 찍히고 맨 먼저 나온다. 전체의 10~15%만.
- `rep:true` (선택): 한 회차에 여러 번 나와도 되는 카드. 생활형 반복 카드에만.
- `chainOnly:true`: 다른 카드의 `chain`으로만 나오는 후속 카드. 같은 파일 안에 만든다.
- `title`, `text`: 문자열. 시대에 따라 바꾸고 싶으면 `()=>S.year<1980?'...':'...'` 같은 함수도 된다.
- `ch`: 선택지 2~4개. 최소 하나는 돈 없이 고를 수 있어야 한다.
  - `t`: 짧은 문구(20자 안팎). 돈이 드는 선택지는 문구 끝에 `(숫자)`를 붙이고 `need:{money:숫자}`를 같은 숫자로 넣는다.
  - `need` (선택): `{money:n}` 또는 `{face:n}`(체면 n 이상).
  - `fx`: 효과 객체(아래). 효과 없음은 `{}`.

## 텍스트 토큰
`{subj}` 주인공 이름, `{nb}` 이웃 이름(예: 박씨네), `{nbHead}` 이웃 집 어른 이름, `{fam}` 우리 성씨, `{rep}` 대표 이름, `{year}` 올해.
조사는 `{subj:이/가}`, `{subj:을/를}`, `{subj:은/는}`, `{subj:과/와}`, `{subj:으로/로}`, `{nb:이/가}`처럼 쓴다. (앞이 받침 있을 때 / 없을 때 순서)

## 효과 키 (fx)
돈은 내부 단위다. **1단위 ≈ 1978년 돈 2만 6천 원 ≈ 지금 돈 22만 원.** 게임이 그해 물가와 소득 수준에 맞춰 자동으로 키워 보여 주니, 모든 시대에 같은 감각으로 쓴다: 소소 1~4, 보통 5~15, 큼 20~50, 아주 큼 60~150.

| 키 | 뜻 | 보통 크기 |
|---|---|---|
| `money` | 돈 증감 | 위 기준 |
| `face` | 체면 증감 (0~100) | ±1~3, 아주 드물게 ±5. **체면은 잘 오르면 안 된다.** 올리는 것보다 깎이는 경우를 더 자주 만든다 |
| `aff` | 주인공 애정 | ±1~3 |
| `grudge` | 주인공 마음에 쌓인 원한(숨김) | +1~3, 풀릴 때 -1~2 |
| `affAll` | 집 식구 모두 애정 | ±1 |
| `nbj` | 그 이웃과의 정 | ±1~4 |
| `jAll` | 모든 이웃과의 정 | ±1 |
| `ledger` | 정 장부에 남길 한 줄(문자열). `nb` 있는 카드에서만 | |
| `talent` | 주인공 능력치 `{셈:1}` 등. 능력치: 셈, 손재주, 글, 말솜씨, 몸, 끈기, 눈썰미, 마음씨 | ±1~2 |
| `pers` | 주인공 성격 `{모험:1}`. 성격: 성실, 사교, 모험, 온화, 고집 | ±1 |
| `gap` | 가풍 `{d:1}` d=근면(+)↔여유(-), f=체면(+)↔실속(-), s=엄격(+)↔다정(-) | ±1 |
| `tradeY`, `craftY` | 장사·기술 경력 연수 | ±1~3 |
| `land` | 땅 필지 수 증감 | ±1 |
| `repu` | 가게 평판(2000년대 이후) | ±2~8 |
| `house` | `'own'` 내 집, `'apt'` 아파트, `'shack'` 판잣집 | |
| `flag` | 집안 기록 이름(문자열) | |
| `sflag` | 주인공 기록 이름(문자열). `'sick'`는 병, `'mid'`는 중학교 진학 | |
| `sick` / `heal` | `true`면 주인공이 병듦 / 병이 나음 | |
| `mod` | 수입 보정 `{k:'trade'|'craft'|'study',m:1.2,n:3}` (n년 동안 m배) | |
| `chain` | 후속 카드 `{id:'a-010b',in:2}` (in년 뒤). 같은 파일에 chainOnly 카드로 만든다 | |
| `awayYears` | 주인공이 n년 집을 떠남(군대·파견·유학) | |
| `leave` | 주인공이 아주 떠남. 이유 문자열('상경','이민','분가','유학' 등) | |
| `marry` | 주인공 혼인 `'good'|'mid'|'plain'` | |
| `official` | `true`면 주인공이 공무원·관직 | |
| `edu` | 주인공 학력을 이 값 이상으로 | |
| `die` | `true`면 주인공 사망. 아주 드물게, 대개 `rnd` 안에서 낮은 확률로 | |
| `rec` | 주인공 족보 한 줄 기록(과거형 문장). 인생에 남을 일에만 | |
| `recW` | 그 기록의 중요도 1~5 | |
| `recRep` | 대표의 족보 기록 | |
| `rnd` | 확률 결과 `[{p:.3,fx:{...},msg:'결과 문장'},{p:.7,fx:{...},msg:'...'}]` (p 합 ≤ 1) | |
| `dream` | 주인공 아이에게 예체능 꿈을 준다: '음악'|'미술'|'운동'|'연기'|'auto' | |
| `timeDebt` | 이웃 돌봄으로 쌓은 '시간 빚'(2030년대 이후) | +1~3 |

`fx`는 `ctx=>({...})` 함수로 써도 된다(`ctx.subj`, `ctx.nb` 사용 가능). 꼭 필요할 때만.

## 말이 되게 (꼭 지킬 것)
- 글에 주인공 처지가 드러나면 `wc`로 맞춘다: 아이 묘사면 나이, 남편·아내·며느리면 혼인·성별, '혼자 된/홀로 지내는'이면 배우자가 없거나 세상을 떠난 사람(`p=>{const s=p.spouse?P(p.spouse):null;return !s||!s.alive}`), 손주가 있다는 전제면 손주가 있는지.
- 집안 형편이 드러나면 `cond`로 맞춘다: 가게 이야기면 `S.tradeY>=2`, 가난 묘사면 `S.money<cm(20)`, 차·여행 같은 부유한 이야기면 `S.money>=cm(30)`, 땅 이야기면 `S.land>=1`, 업종이 드러나면 `S.biz`.
- 정답 선택지 금지: 모든 선택지가 무언가를 얻고 무언가를 잃게 한다. '돈 안 들고 이득만 있는 선택지', '손해만 있는 선택지'를 만들지 않는다.
- 생활형 반복 카드(`rep:true`)는 만들지 않는다. 한 번 나오는 이야기로 쓴다.

## 글쓰기 원칙
- 한국어. 장면 하나가 떠오르는 구체적인 1~3문장. 그 시대 생활 소품과 말투를 살린다(연탄, 곗돈, 전차, 국민학교, 삐삐, PC방, 배달앱, 키오스크 등).
- 실존 인물 이름, 상표·회사 이름, 신문 기사 인용은 쓰지 않는다. 역사 사건은 이름만 배경으로 쓸 수 있지만 평가하지 않는다.
- 선택지는 어느 쪽에도 대가가 있게 만든다. 정답 같은 선택지를 피한다. 돈을 아끼면 정이나 애정을 잃고, 체면을 챙기면 돈이 나가는 식.
- 원한(grudge)은 자녀의 바람(desire)과 어긋나는 선택에서 쌓이게 한다.
- 체면(face)은 아껴 쓴다. 대부분의 카드에서 체면을 올리지 않는다.
- 후속 카드(chain)를 적극 써서 몇 년 뒤 결과가 돌아오는 이야기를 만든다. 전체의 20% 정도.
- 같은 소재를 반복하지 않는다.
